ERP Database Analysis Portfolio

Repositório dedicado a estudos e análises técnicas em ambiente local de homologação do sistema BIG ERP.

O projeto contém:

- investigações de inconsistências;
- consultas SQL;
- validações de integridade;
- documentação técnica;
- simulações de cenários operacionais em tempo real.

Todos os testes foram realizados em base de dados exclusiva para estudos, sem utilização de informações reais de clientes ou ambientes de produção.

Stack: SQL • HeidiSQL • MySQL • ERP BIG/Linx
